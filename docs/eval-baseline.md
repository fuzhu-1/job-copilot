## 使用说明

1. 启动系统，在「评测报告」页点「运行评测」（或 `POST /api/eval/runs`）。
2. 把返回的 `run_id`、通过率与分类型平均分填入上表。
3. 每次功能改动后重跑评测：若通过率低于基线，先修复再合入。
4. 基线调整必须说明理由（如 golden set 扩充、judge 标准收紧）。
